FILE NAMING GUIDE
==================

Drop your files into this folder (assets) using these exact names,
and they'll show up on the site automatically without touching the code.

IT section:
- it-project-1.jpg   (project 1 image)
- it-project-2.jpg   (project 2 image)
- it-project-3.jpg   (project 3 image)

Games section:
- game-project-1.mp4  (project 1 video)
- game-project-2.mp4  (project 2 video)
- game-project-3.jpg  (project 3 image)

Resume:
- cv.pdf

Notes:
------
- If you swap an image for a video (or vice versa), update the file
  extension in script.js inside the `data` object (look for "media" and "type").
- To rename files, update the same spot in the code (data.it.cards / data.games.cards).
- Videos autoplay muted and loop by default so they don't annoy visitors.
